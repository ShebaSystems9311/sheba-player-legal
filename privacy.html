01 About This Policy

This Privacy Policy describes the information practices of Sheba Systems with respect to Sheba Player, a desktop media player application available on the Microsoft Store. It explains what data the application does and does not collect, how locally stored preferences are handled, and what rights you have as a user.

This policy applies to all versions of Sheba Player distributed through the Microsoft Store and applies regardless of the device, operating system version, or Windows account you use to run it.

By installing or using Sheba Player you acknowledge that you have read and understood this policy. If you do not agree with this policy, please uninstall the application.

02 About Sheba Systems

Sheba Player is developed and published by Sheba Systems, an independent software developer based in Mombasa, Kenya. Sheba Systems is the data controller for the purposes of this policy, though as described throughout this document, no personal data is collected or processed.

Sheba Systems operates as an independent developer and is not affiliated with Microsoft Corporation beyond the use of the Microsoft Store as a distribution platform.

03 About Sheba Player

Sheba Player is a desktop media player for Windows. Its core function is to play audio and video files stored on your local device or connected storage. The application includes features such as:

  • Audio and video playback with format support via local decoding
  • A graphical equalizer and audio enhancement tools
  • A media library that indexes files from folders you select
  • Playlist creation, management, and persistence
  • Visual spectrum analysis and audio visualizations
  • A mini player mode and multiple window layouts
  • Customizable themes and display settings

All of these features operate entirely on your local device. None of them require or initiate any connection to the internet or to any external server.

05 Data Stored Locally on Your Device

Sheba Player saves a small amount of data to your local device in order to remember your preferences between sessions. This data never leaves your device and is never accessible to Sheba Systems or any third party.

What is stored locally

Data Item Purpose Location
Playback preferences Volume, speed, equalizer settings, theme choice Local only
Queue and playlist data Restores your last queue on next launch Local only
Media library index Stores file paths, metadata, play counts, and ratings for files in folders you add to the library Local only
Window layout preferences Size, position, and state of player windows Local only
Privacy agreement record Records that you have accepted this policy so the prompt is not shown again Local only

Where this data is stored

All locally stored data is written to your Windows application data folder, typically located at %APPDATA%\sheba-player. This folder is part of your Windows user profile and is under your full control.

How to remove this data

You can delete all locally stored preferences and library data at any time by deleting the folder at %APPDATA%\sheba-player. Uninstalling Sheba Player through Windows Settings or the Microsoft Store will also remove this data.

06 Network and Internet Access

Sheba Player does not make any network connections during normal operation. It has no backend server, no API endpoints, no cloud synchronisation, and no update-check mechanism built into the application itself.

Important Note The only network activity associated with Sheba Player is the Microsoft Store's own update and licensing infrastructure, which is managed entirely by Microsoft and is governed by Microsoft's own Privacy Statement, not this policy. Sheba Systems has no access to any data Microsoft collects through Store operations.

The application does not request any network-related permissions beyond those implicitly granted by the Windows operating system to standard desktop applications. It does not open ports, does not listen for incoming connections, and does not communicate with any server owned or operated by Sheba Systems.

09 Advertising and Tracking

Sheba Player contains no advertisements of any kind. There are no banner ads, video ads, pop-up promotions, sponsored content, or in-app purchase prompts within the application.

Sheba Player contains no tracking technology of any kind. There are no tracking pixels, no cookies, no fingerprinting scripts, no session recording tools, and no behavioural profiling systems.

Sheba Systems does not sell, rent, lease, or otherwise share user data with advertisers, data brokers, or marketing platforms — because we possess no such data to share.

10 Children's Privacy

Sheba Player does not collect personal information from any user, including children under the age of 13 (or the applicable age of digital consent in your jurisdiction). Because no data of any kind is collected, transmitted, or stored remotely, Sheba Player inherently complies with the Children's Online Privacy Protection Act (COPPA), the UK Children's Code, and equivalent regulations worldwide.

Parents and guardians can allow children to use Sheba Player with confidence that no personal information will be collected as a result.

11 Your Rights and Controls

Because Sheba Systems does not collect or hold any personal data about you, many standard data rights (such as the right to access, correct, or delete data held by a company) are satisfied by default — there is simply no data held about you for us to provide, correct, or delete.

Controls available to you

  • Delete local data: Delete the folder at %APPDATA%\sheba-player at any time to remove all locally stored preferences, library index, and settings.
  • Uninstall: Uninstalling Sheba Player through Windows Settings or the Microsoft Store removes the application and its associated local data.
  • Review stored data: The local data folder contains plain JSON files which you can open and inspect in any text editor.

If you have questions about your rights under Kenyan data protection law or any other applicable regulation, you are welcome to contact us using the details in Section 16.

12 Data Security

Because Sheba Player does not transmit any data over a network, the attack surface associated with data interception or server-side breaches does not exist for this application.

Locally stored preferences are written in plain text to your Windows user profile directory. The security of this data is therefore equivalent to the security of your Windows user account. We recommend that you use a strong Windows login password and keep your operating system updated to protect all local application data on your device, not just data associated with Sheba Player.

Sheba Systems cannot access your local application data under any circumstances, including through remote support sessions, and will never ask you to share the contents of your local data folder.

13 Media Files and Content

Sheba Player accesses media files solely for the purpose of playback, at your explicit direction. The application reads file metadata (such as title, artist, album, and duration) in order to display it to you within the interface and to populate your library. This metadata is stored in your local library index as described in Section 5.

Sheba Systems has no access to your media files, their names, their contents, or your listening habits. No information about what you play, how often you play it, or when you play it is ever transmitted outside your device.

Sheba Player does not scan your device beyond the folders you explicitly add to the media library. It only accesses files you directly open or add to the queue.
